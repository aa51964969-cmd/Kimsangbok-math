# 상분학 · T함수론

**김상복 (Sangbok Kim)** — 독립 수학 연구자, 강원도 춘천

이 저장소는 제가 독자적으로 개발해 온 두 갈래의 수학 연구를 공개하는 곳입니다.
논문과 그래프 자료를 자유롭게 내려받아 쓰실 수 있습니다.

---

## 1. 상분학 (Sangbun Vector Theory)

2000년부터 개발해 온 기하·벡터 이론입니다.
곡선 위의 점으로부터 방향벡터를 **유한한 유클리드 작도**만으로 구성합니다. 미적분에 기대지 않는 접근이라는 점이 핵심입니다.

- 기본 관계식: **AA₁₂ = AA₆ + AA₁₁**
- 분기를 지배하는 기하 불변량: **@ = |OA₁| / |AA₁|**
- Z1 · Z2 · Z3 세 모드에 대해 @<1, @>1, @=1 전 분기 공식 완성

### 네 가지 벡터 법칙

| 법칙 | 내용 |
|---|---|
| 균형 법칙 (Balance Law) | 벡터 합의 균형 구조 |
| 극한 방향 법칙 (Limit Direction Law) | 극한에서 ±45°로 수렴 |
| 상분 기울기 변환 | 기울기의 상분 변환 관계 |
| 진동 평균 회복 | 진동의 평균값 회복 성질 |

### 닫힌형 압축

A3a–A5b 아홉 점을 스칼라 λ 하나로 흡수하고 A10′을 부호식으로 소거하여, A1–A12 사슬을 거치지 않는 직접 계산식을 유도했습니다.
회전좌표계 (τ, β)에서 A7 이후 회전불변임을 확인했습니다.

## 2. T함수론 (T-Function Theory)

2026년 5월에 시작한 별개의 이론입니다. **상분학과는 무관합니다.**

감마 함수 대신 조합적 수열 **T(p, q)** 를 써서 정수·분수·복소수의 계승(factorial)을 계산합니다.

- T(p, q)의 닫힌형 유도
- 분수 계승 보간법, 복소 계승 공식
- 상수 **C = lim(S(n) − H(n)) ≈ −0.8660648296…** 발견
  - mpmath로 60자리 이상 확인
  - 지수적분 Ei를 이용한 적분 표현으로 200자리 이상 정밀도 달성
  - PSLQ 검색 결과 표준 상수들의 조합으로는 닫힌형이 나오지 않음
